# Introduccion de github

 - GitHub es una plataforma de desarrollo y colaboración creada en 2008 y adquirida por Microsoft en 2018 por aproximadamente 7.5 mil millones de dólares. Su principal función es permitir que los desarrolladores almacenen, administren y compartan código utilizando Git, un sistema de control de versiones creado por Linus Torvalds en 2005. Gracias a Git, es posible guardar un historial de los cambios realizados en un proyecto, comparar versiones y recuperar información anterior sin perder el trabajo realizado.
